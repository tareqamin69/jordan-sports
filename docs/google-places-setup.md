# تفعيل Google Places (اختياري) لاستيراد الملاعب من Google Maps

لما صاحب الملعب يلصق رابط ملعبه من Google Maps، الموقع **دايمًا** بيقرأ من الرابط نفسه (ببلاش):
اسم الملعب، مكانه على الخريطة، المحافظة وأقرب منطقة.

إذا فعّلت مفتاح Google Places، بنعبّيله كمان: **رقم التلفون، الموقع الإلكتروني، العنوان، وساعات
الدوام** (بتنطبق على كل ملعب بيضيفه). إذا ما في مفتاح، أو صار أي خطأ، الموقع بيكمّل عادي بالقراءة
من الرابط بس، وما حدا بيعلق.

> الصور: **ما بنسخ ولا صورة من Google**. صاحب الملعب بيرفع صوره هو.

---

## 1. اعمل مشروع على Google Cloud

1. افتح <https://console.cloud.google.com> وادخل بحساب Google تبع الشركة.
2. فوق، اضغط على قائمة المشاريع ← **New Project**.
3. سمّيه مثلًا `jorena-places` واضغط **Create**، وبعدين اختاره.

## 2. فعّل Places API (New)

1. من القائمة: **APIs & Services ← Library**.
2. ابحث عن **Places API (New)** (انتبه: الجديد، مش "Places API" القديم).
3. اضغط **Enable**.

## 3. فعّل الفوترة (Billing)

Google بتطلب بطاقة حتى لو استخدامك ضمن المجاني.

1. **Billing ← Link a billing account** وضيف بطاقة.
2. اعمل تنبيه مصاريف: **Billing ← Budgets & alerts ← Create budget**، حط مثلًا 1 دولار، وخلي
   التنبيه يوصلك عالإيميل. هيك إذا صار أي مصروف بتعرف فورًا.

## 4. حدّد سقف يومي عشان تضل ضمن المجاني

بنستخدم طلب واحد (Text Search) لكل رابط، ومعه التلفون وساعات الدوام. Google بتعطي عدد مجاني كل
شهر لهاد النوع من الطلبات (لما كتبنا هالدليل كان حوالي **1,000 طلب بالشهر**؛ الأرقام بتتغير، فتأكد
من صفحة الأسعار: <https://developers.google.com/maps/billing-and-pricing/pricing>).

عنا حمايتين:

- **من عنا:** السيرفر ما بيعمل أكثر من **30 طلب باليوم** (`GOOGLE_PLACES_DAILY_CAP`)، يعني أقل من
  1,000 بالشهر. وكمان كل مستخدم إله حد بالساعة، وكل نتيجة بتنحفظ 30 يوم عشان ما نسأل Google
  مرتين عن نفس المكان.
- **من Google (احتياط):**
  1. **APIs & Services ← Places API (New) ← Quotas & System Limits**.
  2. دوّر على **Text Search requests per day** (أو "SearchText requests per day").
  3. اضغط القلم ✏️ وحط **30**، واحفظ.

## 5. اعمل المفتاح وقيّده

1. **APIs & Services ← Credentials ← Create credentials ← API key**.
2. اضغط على المفتاح الجديد ← **Edit**:
   - **Application restrictions:** اختار **IP addresses** وحط عنوان السيرفر (IP) تبع الموقع بس.
   - **API restrictions:** اختار **Restrict key** وعلّم **Places API (New)** بس.
3. **Save**. (التقييد بياخد كم دقيقة لحتى يشتغل.)

> المفتاح سرّي: لا تحطه بالكود، ولا بـ git، ولا تبعثه بالشات أو الإيميل.

## 6. حطه على السيرفر

ادخل على السيرفر (SSH) وافتح ملف الإعدادات:

```bash
sudo nano /opt/jordan-sports/staging.env
```

ضيف هالسطر (مكان `...` حط المفتاح):

```
GOOGLE_PLACES_API_KEY=...
```

اختياري: إذا بدك سقف يومي غير 30:

```
GOOGLE_PLACES_DAILY_CAP=30
```

احفظ (Ctrl+O ثم Enter ثم Ctrl+X)، وبعدين أعد تشغيل الـ API:

```bash
cd /opt/jordan-sports/app/infra/staging && sudo docker compose up -d api
```

## 7. جرّب

افتح صفحة "سجّل ملعبك"، والصق رابط مكان من Google Maps، واضغط "اقرأ الرابط". إذا ظهرت رسالة
إنه عبّينا "التلفون والعنوان وساعات الدوام من Google"، يعني المفتاح شغّال. إذا ظهرت "الاسم
والموقع من الخريطة" بس، يعني الموقع شغّال بدون المفتاح (راجع الخطوات 2 و5 و6).

## لإيقافه

احذف سطر `GOOGLE_PLACES_API_KEY` من الملف وأعد تشغيل الـ API (نفس أمر الخطوة 6). الاستيراد من
الرابط بضل شغّال ببلاش.
